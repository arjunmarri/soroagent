Troubleshooting

If the connection test fails:

Ollama isn't running

Open the Ollama app (macOS menu bar / Windows system tray), or run ollama serve. Then download a model, for example ollama pull llama3.2.

403 Forbidden

SoroAgent normally handles this. If your setup still rejects the extension, allow extension origins and restart Ollama:

macOS

launchctl setenv OLLAMA_ORIGINS "chrome-extension://*,moz-extension://*"

Windows (PowerShell or Command Prompt)

setx OLLAMA_ORIGINS "chrome-extension://*,moz-extension://*"

Then quit Ollama completely and start it again.

Cloud API errors

Key rejected (401/403): check you copied the whole key and that billing or credits are set up on the provider's site. Rate limited (429): wait a minute, or raise your account's limits. Model not found: pick another model from the list.

LM Studio, llama.cpp, Jan and others

Start the app's local server and use its URL ending in /v1, for example http://127.0.0.1:1234/v1 for LM Studio. In LM Studio, load a chat model and turn on “Enable CORS” if requests fail.
